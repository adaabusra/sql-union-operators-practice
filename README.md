
# SQL UNION Operators Practice

## About the Project
This project contains SQL exercises using set operators in PostgreSQL. The exercises are based on the `actor` and `customer` tables.

## Topics Covered
- UNION
- INTERSECT
- EXCEPT

## Exercises

### 1. UNION
Combines the `first_name` values from the `actor` and `customer` tables and returns distinct results.

### 2. INTERSECT
Returns the common `first_name` values found in both the `actor` and `customer` tables.

### 3. EXCEPT
Returns the `first_name` values that exist in the `actor` table but not in the `customer` table.

## Tables Used
- actor
- customer

## Column Used
- first_name

## Tools
- PostgreSQL
- SQL

## Purpose
The purpose of this project is to practice SQL set operators and understand how to combine, compare, and retrieve data from multiple tables.
